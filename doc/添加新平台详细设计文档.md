# 添加新平台详细设计文档

> **用途**：指导 agent 完成新票务平台的接入开发
> **适用架构**：src/common/platform/（配置驱动的新架构）

---

## 1. 概述

本系统的平台体系指**外部票务交易平台**（如猎人、省APP、芒果、蚂蚁、洋葱、影划算等）。每个平台提供订单列表获取、报价提交、解锁座位、提交取票码、转单等接口。接入新平台需要在以下 7 个位置新增代码。

## 3. 步骤详解

### 步骤 1：添加平台配置

**文件**：`src/common/platform/configs/platform-config.js`

在 `PLATFORM_CONFIGS` 对象中新增一个配置项。该配置定义了平台的基本信息、特性、API 方法映射、参数转换规则。

#### 配置项结构

```javascript
export const PLATFORM_CONFIGS = {
  // ... 现有配置

  newplatform: {
    name: "newplatform", // 平台代码（唯一标识）
    displayName: "新平台", // 显示名称
    features: {
      hasTransferFee: false, // 是否有转单手续费
      priceStep: 1, // 价格步进（0.1 或 1）
      isNeedRuleId: true, // 是否需要规则ID
      supportAsyncSubmit: false, // 是否支持异步提交报价
      unlockBeforeTicket: true, // 出票前是否需要解锁座位
      needConfirmOrder: false // 是否需要确认接单
    },
    api: {
      getOrderList: "queryStayOfferList", // 获取订单列表的方法名
      submitOffer: "submitOffer", // 提交报价的方法名
      unlockSeat: "unlockSeat", // 解锁座位的方法名
      submitTicket: "submitTicketCode", // 提交取票码的方法名
      transferOrder: "transferOrder" // 转单的方法名
    },
    params: {
      orderIdKey: "id", // 订单ID字段名
      orderNumberKey: "order_number", // 订单号字段名
      unlockParams: order => ({
        // 解锁座位的参数转换
        order_id: order.id
      }),
      submitParams: (order, qrcode) => ({
        // 提交取票码的参数转换
        order_number: order.order_number,
        ticket_code: qrcode
      }),
      transferParams: (order, reason) => ({
        // 转单的参数转换
        order_number: order.order_number,
        reason: reason || "无法出票"
      }),
      offerParams: (order, price) => ({
        // 提交报价的参数转换
        order_number: order.order_number,
        price
      })
    },
    transformOrder: order => ({
      // 平台订单 → 系统统一格式
      ...order,
      plat_name: "newplatform"
    })
  }
};
```

#### 关键字段说明

| 字段                          | 说明                                    | 参考值                             |
| ----------------------------- | --------------------------------------- | ---------------------------------- |
| `name`                        | 平台唯一代码，与文件名、注册名一致      | `"lieren"`, `"mangguo"`            |
| `displayName`                 | 前端展示的平台名称                      | `"猎人"`, `"芒果"`                 |
| `features.priceStep`          | 报价价格步进，`1`=整数，`0.1`=0.1步进   | 参考 `ONE_STEP_PLAT_LIST`          |
| `features.needConfirmOrder`   | 是否需要确认接单，供 `OfferQueue` 判断  | `true` 时队列会调 `confirmOrder()` |
| `features.supportAsyncSubmit` | 是否异步返回报价结果                    | `true` 时会轮询报价状态            |
| `api.*`                       | 方法名必须与 API 层实际导出的方法名一致 | 见步骤 4                           |

### 步骤 2：创建请求实例

**文件**：`src/utils/http/newplatform-request.js`

请求实例负责 API 调用的底层通信，包括：

- **Header 注入**：根据平台要求注入 AK/SK、Token、时间戳、签名等
- **环境切换**：开发环境通过 Vite proxy 转发，生产环境直连后端 API
- **错误处理**：业务错误码拦截、登录失效检测、网络异常提示
- **URL 重写**：开发环境加 `/svpi` 前缀，生产环境加后端域名

#### 模板代码

```javascript
// src/utils/http/newplatform-request.js
// 新平台 API 请求实例

import axios from "axios";
import { ElMessage } from "element-plus";
import { platTokens } from "@/store/platTokens";

const createAxios = ({ timeout = 25 }) => {
  const instance = axios.create({
    baseURL: "",
    timeout: timeout * 1000
  });

  const NODE_ENV = process.env.NODE_ENV;
  const IS_DEV = NODE_ENV === "development";

  // 请求拦截器
  instance.interceptors.request.use(
    config => {
      if (config.url.indexOf("/newplatform/") !== -1) {
        const tokens = platTokens();
        // 注入平台 token
        config.headers["Authorization"] = tokens.newplatformToken || "";
        config.headers["Content-Type"] = "application/json";

        // 环境适配
        if (IS_DEV) {
          config.url = config.url.replace("/newplatform", "/svpi/newplatform");
        } else {
          config.url =
            "http://后端服务器地址:3000" +
            config.url.replace("/newplatform", "/newplatform");
        }
      }
      return config;
    },
    error => Promise.reject(error)
  );

  // 响应拦截器
  instance.interceptors.response.use(
    response => {
      const data = response.data;
      // 检查业务错误
      if (data && data.code !== 0) {
        const msg = data.msg || "请求失败";
        ElMessage.error(msg);
        return Promise.reject(data);
      }
      return data;
    },
    error => {
      // 网络错误处理
      ElMessage.error("网络连接异常，请稍后再试");
      return Promise.reject(error);
    }
  );

  return instance;
};

export default createAxios;
```

### 步骤 3：创建 API 封装层

**文件**：`src/api/newplatform-api.js`

API 层封装具体的 HTTP 请求方法，供适配器和队列调用。方法名必须与 `platform-config.js` 中 `api` 字段定义的方法名一致。

#### 模板代码

```javascript
// src/api/newplatform-api.js
// 新平台 API 接口列表

import createAxios from "@/utils/http/newplatform-request";

const createApi = () => {
  let axios = createAxios({});

  // 获取待报价/待出票订单列表
  const queryStayOfferList = (params, config = {}) =>
    axios.get("/newplatform/order/stay-offer-list", { params, ...config });

  // 提交报价
  const submitOffer = (data, config = {}) =>
    axios.post("/newplatform/order/submit-offer", data, config);

  // 解锁座位
  const unlockSeat = (params, config = {}) =>
    axios.get("/newplatform/order/unlock-seat", { params, ...config });

  // 提交取票码
  const submitTicketCode = (data, config = {}) =>
    axios.post("/newplatform/order/submit-ticket-code", data, config);

  // 转单（无法出票时转移给其他人）
  const transferOrder = (data, config = {}) =>
    axios.post("/newplatform/order/transfer", data, config);

  return {
    queryStayOfferList,
    submitOffer,
    unlockSeat,
    submitTicketCode,
    transferOrder
  };
};

export default createApi();
```

> **方法名一致性要求**：`platform-config.js` 的 `api.getOrderList` 映射到 `queryStayOfferList`，`api.submitOffer` 映射到 `submitOffer`，依此类推。适配器通过 `this.api[this.config.api.submitOffer]` 动态调用。

### 步骤 4：创建平台适配器

**文件**：`src/common/platform/adapters/NewPlatformAdapter.js`

适配器继承 `BasePlatformAdapter`，实现平台特定的订单获取和报价提交逻辑。

#### 基类已提供的默认实现

| 方法               | 基类默认行为                         | 是否需要重写                       |
| ------------------ | ------------------------------------ | ---------------------------------- |
| `fetchOrderList()` | 抛出错误                             | **必须重写**                       |
| `submitOffer()`    | 抛出错误                             | **必须重写**                       |
| `unlockSeat()`     | 通用解锁逻辑，调 `api.unlockSeat`    | 可选重写                           |
| `submitTicket()`   | 通用提交逻辑，调 `api.submitTicket`  | 可选重写                           |
| `transferOrder()`  | 通用转单逻辑，调 `api.transferOrder` | 可选重写                           |
| `confirmOrder()`   | 抛出错误（默认不需要）               | 按需（`needConfirmOrder=true` 时） |

#### 模板代码

```javascript
// src/common/platform/adapters/NewPlatformAdapter.js
// 新平台适配器

import BasePlatformAdapter from "../../core/BasePlatformAdapter.js";
import newPlatformApi from "@/api/newplatform-api.js";

/**
 * 新平台适配器
 */
class NewPlatformAdapter extends BasePlatformAdapter {
  /**
   * @param {Logger} logger - 日志实例
   * @param {boolean} isTestOrder - 是否为测试订单模式
   */
  constructor(logger, isTestOrder = false) {
    const apiInstance = newPlatformApi();
    super("newplatform", apiInstance, logger, isTestOrder);
  }

  /**
   * 获取待报价/出票订单列表
   * @param {Object} params - 查询参数（如分页、时间范围）
   * @returns {Promise<Array>} 订单列表
   */
  async fetchOrderList(params = {}) {
    // 1. 调 API 获取原始订单列表
    const orderList = await this.api.queryStayOfferList({
      page: params.page || 1,
      page_size: params.page_size || 50,
      ...params
    });

    // 2. 用 config.transformOrder 统一格式
    return (orderList?.data?.list || []).map(order =>
      this.config.transformOrder(order)
    );
  }

  /**
   * 提交报价
   * @param {Object} params - 报价参数（含订单信息、价格等）
   * @returns {Promise<Object>} 报价结果
   */
  async submitOffer(params) {
    const offerParams = this.config.params.offerParams(
      params.order,
      params.price
    );
    const result = await this.api.submitOffer(offerParams);
    return result;
  }
}

export default NewPlatformAdapter;
```

### 步骤 5：创建报价队列

**文件**：`src/common/platform/queues/NewPlatformOfferQueue.js`

队列继承 `BaseOfferQueue`，负责轮询获取订单、筛选有登录信息的影院、入队处理。

#### 模板代码

```javascript
// src/common/platform/queues/NewPlatformOfferQueue.js
// 新平台报价队列

import BaseOfferQueue from "../../core/BaseOfferQueue.js";
import NewPlatformAdapter from "../adapters/NewPlatformAdapter.js";
import { GET_ALL_APP_LOGIN_LIST } from "@/common/constant.js";

class NewPlatformOfferQueue extends BaseOfferQueue {
  constructor(isTestOrder = false) {
    const adapter = new NewPlatformAdapter(null, isTestOrder);
    super(adapter, "newplatform", isTestOrder);
  }

  /**
   * 获取订单列表并推送
   */
  async fetchOrders() {
    try {
      // 1. 获取待处理订单
      const orderList = await this.platformAdapter.fetchOrderList();

      // 2. 获取有登录信息的影院
      const loginInfoList = GET_ALL_APP_LOGIN_LIST();
      const appNames = loginInfoList
        .filter(info => info.session_id)
        .map(info => info.app_name);

      // 3. 筛选该平台下可处理的订单
      const availableOrders = orderList.filter(order =>
        appNames.includes(order.app_name)
      );

      // 4. 逐个入队处理
      for (const order of availableOrders) {
        await this.handleNewOrder(order);
      }
    } catch (error) {
      console.error(`[NewPlatform] 获取订单列表异常:`, error.message);
    }
  }
}

export default NewPlatformOfferQueue;
```

### 步骤 6：创建订单获取器

**文件**：`src/common/platform/fetchers/NewPlatformOrderFetcher.js`

订单获取器继承 `BaseOrderFetcher`，负责检测新出票订单、记录过滤、事件分发。

#### 模板代码

```javascript
// src/common/platform/fetchers/NewPlatformOrderFetcher.js
// 新平台订单获取器

import BaseOrderFetcher from "../../core/BaseOrderFetcher.js";

class NewPlatformOrderFetcher extends BaseOrderFetcher {
  constructor() {
    super("newplatform");
  }

  /**
   * 获取新订单
   */
  async fetchNewOrders() {
    // 调 API 获取已出票的新订单
    const orders = await this.api.queryNewOrders();
    return orders || [];
  }

  /**
   * 处理新订单
   */
  async processOrder(order) {
    // 记录、去重、触发出票完成事件
    await this.recordOrder(order);
    this.emit("order_completed", order);
  }
}

export default NewPlatformOrderFetcher;
```
