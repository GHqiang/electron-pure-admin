## 二、报价侧（offerManage.js）

### calcSteps 拼装段（getEndMatchOfferRule + getMinAmountOfferRule）

```
初始匹配命中N条
→ 电影格式过滤剩N条            （filmTypeFlag 过滤后，ume 内联过滤非独立方法）
→ 会员日规则命中(X元)           （onlyMemberDayRuleList 命中即返回）
→ 券库存过滤剩N条               （fixedAmountRuleList 库存+当日票数过滤后）
→ 会员价加价命中(X元)           （memberOfferAmount 计算完成）
→ 定价策略段                     （仅固定价 / 仅会员价 / 固定 vs 会员取低，对照 chenxing 模式）
```

- `getMinAmountOfferRule(ruleList, order, movieInfo, calcSteps = [])` 签名加 `calcSteps = []`（默认值兼容其它调用点）
- 返回前：`const endRuleCopy = JSON.parse(JSON.stringify(endRule)); endRuleCopy.calc_path = calcSteps.join("→"); endRuleCopy.hit_rule_name = endRule.ruleName || "";`
- `calc_path`/`hit_rule_name` 由 BaseOfferQueue serOrderInfo 收口（截断 500）入库，本文件只负责挂到 offerRule

## 三、出票侧（buyTicket.js）

### 采集字段（oneClickBuyTicket 成功路径 return 前）

| 字段 | 来源 | 单位 |
|------|------|------|
| `paymentAmount` | `createOrderRes?.paymentAmount`（第 876 行既有变量） | **已是元**（与 quan_fee_total / real_member_price 元值直接比较），`?? null` 原样采集 |
| `cardBalance` | `cardList?.find(cardNo==card_id)?.cardAmount`（if(card_id) 块内） | **原始为分**，采集统一转元 `cardBalance / 100`（与 jinyi 等系列口径一致；null 兜底） |
| `coupons` | `(useQuan || []).slice(0, 10).map({couponType, couponCode, couponName})` | 快照数组 |
| `usePath` | `buildTicketUsePath({offer_type, useQuan, cardNum, cardBalance, paymentAmount, currentParamsInx})` | 一句话路径 |

### 作用域处理

- `cardBalance` 原声明在 `if (card_id)` 块内（`let cardBalance = ...`），return 处不可访问 → **提升为 `let cardBalance = null;`**（if 块前），块内改赋值（照 jinyi 模式）；块内既有 `cardBalance / 100` 日志/同步逻辑不受影响
- `cardNum` 来自 useQuanOrCard 解构（函数级作用域），return 处可直接访问，无需提升（块内 `const cardNum = card_id;` 为既有遮蔽，未动）

### buildTicketUsePath 方法

方法体照抄 jinyi（换号N次 / 用券N张→卡尾号付券手续费 / 用卡尾号→支付前余额→实付），保持 ume 文件风格。

## 五、回归风险评估

| 风险 | 等级 | 控制 |
|------|------|------|
| cardBalance 分/元口径错 | 低 | 采集处显式 `/100` 转元 + `== null` 兜底（`null / 100 = 0` 会绕过 null 兜底，故用 `== null ? null :` 判定） |
| 数值列 `""` 写 DECIMAL 报 1366 | 低 | return 处 `paymentAmount ?? null` / cardBalance 三目 null 兜底（与基类收口一致，双层防呆） |
| 提前 return 路径（转单/换号/测试模式）不采集 | 低 | saveTicketRecord 解构默认值兜底（undefined→NULL/空），行为与原一致 |
| calcSteps 拼装引用不存在字段 | 低 | 全部 `?.` / 既有变量保护；失败路径（endRule 为空）不挂 calc_path |
