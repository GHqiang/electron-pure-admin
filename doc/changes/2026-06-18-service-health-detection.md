# 2026-06-18 服务健康检测：自动退出登录 + 微信通知

## 修改文件

- `src/utils/http/sv-request.js`

## 核心变更

在 `sv-request.js` 的 axios 响应拦截器中增加了**服务健康检测**功能：

### 检测逻辑

- 监控 HTTP 状态码：`502`（网关错误）、`503`（服务不可用）、`504`（网关超时）、`429`（请求过多/负载满）
- 使用计数器 `serviceDownCount` 追踪**连续**失败次数
- 连续失败达到 **10 次**（`SERVICE_DOWN_THRESHOLD`）时触发退出登录
- 任意请求成功后自动重置计数器，避免偶发错误误触发

### 退出登录流程

1. 清除 `selfToken`、`userInfo`、`user-info` 等本地存储
2. 调用 `tokens.removeSelfPlatToken()` 清除 Pinia 中的 token
3. 刷新页面（`location.reload()`）

### 微信通知

- 通过已有的 `sendWxPusherMessage` 发送通知
- 消息内容包含具体的状态码描述和连续失败次数
- 内置 **5 分钟冷却时间**，避免短时间内重复发送
- 使用 `msgType: 9`（日志上传异常类型）

### 防护机制

- `hasLoggedOut` 标志位防止重复触发退出登录
- `lastNotifyTime` 控制微信通知频率
- 成功响应自动重置所有状态

## 回归风险评估

- **低风险**：新增逻辑仅在检测到特定错误状态码时触发，不影响正常请求流程
- **注意**：`SERVICE_DOWN_THRESHOLD`（3次）和 `NOTIFY_COOLDOWN_MS`（5分钟）为可调参数，可根据实际情况调整
