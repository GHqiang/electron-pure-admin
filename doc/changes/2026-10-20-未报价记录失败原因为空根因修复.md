# 2026-10-20 未报价记录「失败原因」为空根因修复

> 关联分析：`reports/analyze-issue/2026-10-20-未报价记录失败原因为空.md`（本地只读取证，不入库）
> 范围：客户端报价失败记录；不改后端表结构，不改报价成功/失败判定逻辑。

## 一、根因

近 7 天 `offer_record_fail` 真实失败 206,872 行，其中 `err_msg` 为空 287 行，分两类：

1. **254 行（88%）：lieren/bona 169 + lieren/lma 85**
   - 平台提交返回 `{"message":"已自动报价","code":1}`
   - `BaseOfferQueue.singleOffer` 已识别「猎人已自动报价」，但 return 时只带 `offerRule/cinemaInfo/cacheHit`，**漏了 `err_msg`**
   - 入库原因空，`getOfferFailType("")` → `err_type=NULL`
2. **33 行（12%）：Wanda 系列（yinghuasuan 15、haha 8、mayi 6、mahua 4）**
   - `getMovieInfo` 返回 null / `getTargetShow` 匹配不到场次
   - 原代码静默 `return null`，没有 `errorSave`，`buildErrorResponse` 拿不到原因
   - `getEndOfferPrice` 返回 `hasEndPrice:false, err_msg:""`

## 二、修改文件与内容

| 文件 | 修改 |
|---|---|
| `src/common/core/BaseOfferQueue.js` | ①「猎人已自动报价」return 补 `err_msg:"猎人已自动报价"`；②`!endPrice` 时 `err_msg` 为空补「未获取到最终报价（场次/影片/价格/规则匹配失败）」；③`addOrderHandleRecord` 失败记录最后兜底「提交报价未确认成功（平台未返回明确原因）」，成功记录保持空串 |
| `src/common/autoTicket/buyTicket/wanda/offerManage.js` | `getMovieInfo` 为 null 时 `errorSave("获取目标影片信息失败")`，供 `buildErrorResponse` 取到原因 |
| `src/common/autoTicket/buyTicket/wanda/cinemaManage.js` | `getTargetShow` 的 `!dateInfo`（首次/回退日期）都补 `errorSave("匹配万达影片放映场次失败")`；日志「次日重试」改为「回退前一日重试」，与实际 `getPreviousDay` 一致（行为不变） |
| `src/common/constant.js` | `getOfferFailType` 补「匹配万达影片放映场次失败 / 获取电影信息失败 / 未获取到最终报价 / 场次/影片/价格/规则匹配失败」→ 7；「提交报价未确认成功」→ 12 |
| `src/components/HistoryOfferRecord.vue` | 历史空原因显示「未记录失败原因（历史数据）」；`err_type` 为空显示「未分类」 |
