## 核心变更说明

### 1. 新增两类（此前只有测试、实现缺失）

- `13: "超时或过期未提交"` —— `报价已过截止时间` / `提交报价前检测到已过截止时间` / `订单报价处理超时` / `订单报价截止时间小于等于…` / `报价处理超时`
- `14: "黑名单或售罄不报价"` —— `命中万达黑名单标签` / `当前场次已售罄` / `当前场次座位已售罄` / `该电影标签为影展`

> 13/14 的编号在 2026-10-11「原价不报」改动时被刻意绕开（当时实现停留在 stash），本次把该 WIP 落地。`err_type >= 16` 视为「入队前丢弃」的统计口径不受影响（`auto-ticket-service/api/statisticalAnalysis.js` 的 `withRealFailFilter` 只排除 >=16）。

### 2. 补全既有分类的文案匹配

| 分类 | 新增覆盖的文案 |
| --- | --- |
| `2` 该影院无规则 | `按城市/按影片/按电影格式/按电影格式存/按星期几/按会员日筛选后，报价规则为空`、`最终匹配到的报价规则为空` |
| `3` 有规则但未开启 | `按允许报价时间筛选后，报价规则为空` |
| `7` 官网拉取数据失败 | `获取城市影院列表失败`、`获取城市ID失败`、`获取万达目标影院失败`、`获取万达目标影片信息失败`、`获取万达电影放映信息返回空/异常`、`匹配影片放映日期失败`、`该影院没有此影片的排期`、`未获取到最贵座位价格`、`获取座位价格前获取座位失败`、`获取座位布局异常`、`获取成本价失败`、`获取会员价为0` |
